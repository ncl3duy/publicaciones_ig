# Publicaciones NCL3D

Repo **público** para importar las plantillas y publicaciones de NCL3D a Canva como diseños editables (sin los recuadros que aparecen al importar PDFs).

- `plantillas/`: una página HTML por plantilla (`posts/`, `carruseles/`, `reels/`, `historias/`). Cada una se importa a Canva como un diseño.
- `assets/`: logo y fotos que usan las plantillas.

El material de marca completo (guía, tipografías, íconos, fuentes de las plantillas) está en el repo privado `rebranding_instagram`.

No subas acá nada privado: todo lo de este repo se puede ver públicamente.
